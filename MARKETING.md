## 🚀 3. Show HN (Hacker News) Launch Strategy

Hacker News users love minimal, privacy-first technical tools with unique architectural approaches.

### Title Format:
> **Show HN**: *YouTube Hands Free – Open-source MV3 extension using CDP hardware clicks to skip ads*

### Technical Selling Points to Highlight in HN Comments:
1. **Architecture**: Uses `chrome.debugger` API to send OS-level hardware mouse events (`Input.dispatchMouseEvent`) rather than simple DOM clicks.
2. **Performance**: Offloads heavy storage writes to `background.js` and uses heartbeat port self-destruction to prevent memory leaks during extension reloads.
3. **Privacy**: Zero external API dependencies, zero remote analytics.
